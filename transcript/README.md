# Экспорт разговора Codex

conversation.md — читаемая версия, conversation.jsonl — записи сообщений и инструментов.
Это программный экспорт из локального журнала Codex, не команда /export Claude Code и не официальный экспорт интерфейса Codex.
Включены все доступные записи пользовательских сообщений, публичных ответов, вызовов инструментов и их результатов; их текст не редактировался.
Системные инструкции, внутренние рассуждения модели и служебные события не входят в пользовательский транскрипт.
Если инструмент изначально вернул усечённый вывод, экспорт сохраняет именно полученный вывод и не восстанавливает отсутствующий текст.

Транскрипт содержит исходные пути и данные, прочитанные в ходе задания, в том числе текст резюме. Передавать только проверяющему приватно.
